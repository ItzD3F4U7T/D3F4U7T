# Stage 3 References

1. Rama Cont, Arseniy Kukanov and Sasha Stoikov (2014), “The Price Impact of Order Book Events,” *Journal of Financial Econometrics*, 12(1), 47–88. https://doi.org/10.1093/jjfinec/nbt003
   - Primary reference for best-quote order-flow imbalance (OFI) and the relationship between order-book events, depth and short-horizon price changes. Our code uses the best-quote OFI definition as a descriptive feature; it does not implement their empirical regression.

2. Marco Avellaneda and Sasha Stoikov (2008), “High-frequency trading in a limit order book,” *Quantitative Finance*, 8(3), 217–224. https://doi.org/10.1080/14697680701381228
   - Background on limit-order-book state and microstructure. The present project does not implement their market-making model.

3. Álvaro Cartea, Sebastian Jaimungal and José Penalva (2015), *Algorithmic and High-Frequency Trading*. Cambridge University Press. ISBN 9781107091146.
   - Broader mathematical and market-microstructure context.

No external repository implementation or source code is copied into Stage 3. The implementation is original project code; these references support concepts and experimental framing.
