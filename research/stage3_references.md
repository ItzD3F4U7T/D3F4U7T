# Stage 3 References

1. Rama Cont, Arseniy Kukanov and Sasha Stoikov (2014), “The Price Impact of Order Book Events,” *Journal of Financial Econometrics*, 12(1), 47–88. https://doi.org/10.1093/jjfinec/nbt003
   - Basis for the best-quote event order-flow imbalance formulation. OFI here is a descriptive feature, not a trading rule.

2. Marco Avellaneda, Sasha Stoikov (2008), “High-frequency trading in a limit order book,” *Quantitative Finance*, 8(3), 217–224. https://doi.org/10.1080/14697680701381228
   - Background on limit-order-book state and microstructure; the present project does not implement their market-making model.

3. Álvaro Cartea, Sebastian Jaimungal and José Penalva (2015), * Algorithmic and High-Frequency Trading*. Cambridge University Press. https://doi.org/10.1017/CBO978131668
   - Broader mathematical and market-microstructure context. Consult the publisher edition for formal definitions.

No external repository implementation or source code is copied into Stage 3. The implementation is original project code; references support concepts and experimental framing.
